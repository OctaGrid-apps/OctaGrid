# OctaGrid.Extensions.Models

Model types shared by [OctaGrid](https://github.com/OctaGrid-apps/OctaGrid), the 3D printer dashboard, and its extensions: connector descriptors and settings, printer telemetry, print files, and the errors a connector reports.

You normally get this package through [`OctaGrid.Extensions.Abstractions`](https://www.nuget.org/packages/OctaGrid.Extensions.Abstractions), which you reference to write an extension.
