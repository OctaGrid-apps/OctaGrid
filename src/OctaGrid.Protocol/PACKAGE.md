# OctaGrid.Protocol

The wire contract between the parts of [OctaGrid](https://github.com/OctaGrid-apps/OctaGrid), the 3D printer dashboard: requests, responses and messages exchanged by its clients, server and agents.

Extensions do not need this package. To write an extension, reference [`OctaGrid.Extensions.Abstractions`](https://www.nuget.org/packages/OctaGrid.Extensions.Abstractions).
